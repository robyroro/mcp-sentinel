# Roadmap

Roadmap items are proposals, not completed features.

## Near term

- Event-by-event Streamable HTTP SSE response inspection.
- Native server registration from the CLI and richer capability-drift workflows.
- PostgreSQL event partition migrations and object-storage payload offload.
- Webhook, email, syslog, and OpenTelemetry delivery adapters with retry dashboards.
- Expanded conformance fixtures for more MCP SDKs.

## Later

- Kubernetes and dedicated-VM sandboxes.
- Clustered gateways and approval coordination.
- Enterprise identity providers and hardware-backed signing.
- Signed MCP server manifests and a reviewed policy marketplace.
- Behavioral anomaly detection that cannot bypass deterministic policy.
- IDE integrations, more transports, and additional SDK languages.
