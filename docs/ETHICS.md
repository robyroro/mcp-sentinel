# Ethics and responsible use

MCP Sentinel is intended to give people and organizations meaningful control over agent/tool activity. It should not be used to conceal surveillance, bypass consent, or imply certainty its controls cannot provide.

Operators should:

- disclose monitoring and payload retention to affected users;
- minimize content collection and reviewer exposure;
- use approvals for accountable control, not rubber-stamping;
- provide clear explanations and appeal/escalation paths;
- test risk rules for disparate false-positive impact;
- avoid using heuristic scores as sole evidence of malicious intent;
- publish compatibility and security limitations honestly;
- coordinate vulnerability disclosure and protect researchers acting in good faith.

The project uses synthetic demo data and deterministic rules so demonstrations do not require private data or opaque paid classifiers.
