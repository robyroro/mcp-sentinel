## [0.1.0] - 2026-07-16

### Added

- Go MCP gateway with stdio supervision and Streamable HTTP proxy modes.
- FastAPI management/control plane, deterministic seed, RBAC, CSRF, policies, sessions, approvals, risk, secrets, reports, audit, and sandboxes.
- Sentinel YAML policy, explainable risk, secret redaction, injection heuristics, path/network/command guards, audit hashing, and Ed25519 exports.
- Next.js responsive console with English/Romanian navigation and 24 Playwright screenshots.
- Demo MCP servers/client, CLI, Celery jobs, PostgreSQL/Redis/MinIO Compose, OpenTelemetry profile, tests, CI, and documentation.
